# paper-writing
philosophy paper writing


## Codex 学术技能

技能已随仓库保存在 `.agents/skills/`，共 9 个入口。使用 Codex 打开此仓库根目录，并重新启动会话以发现技能。

| 技能 | 用途 |
| --- | --- |
| `paper-analysis` | 论文精读与分析 |
| `academic-research-suite` | 学术研究、文献综述、写作与审稿工作流 |
| `academic-literature-route` | 学术文献检索与分析路线 |
| `literature-review-skills` | 文献综述技能导航 |
| `refine-literature-question` | 明确综述问题 |
| `decompose-review-modules` | 拆解综述模块 |
| `compare-research-methods` | 比较研究方法 |
| `map-literature-contradictions` | 梳理文献中的矛盾 |
| `locate-review-research-gap` | 定位研究空白 |

示例：`请使用 paper-analysis 分析我提供的论文。`

源码仓库与固定版本见 [academic-skills-sources.json](academic-skills-sources.json)。各技能的原有说明和许可随文件保留；外部工具、API 密钥或其他运行依赖需按所选工作流配置。
